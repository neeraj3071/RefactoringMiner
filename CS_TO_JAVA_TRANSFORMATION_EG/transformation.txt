KEY OBSERVATIONS
════════════════════════════════════════════════════════════════════════════════

✓ C1 (Console.WriteLine): Direct API mapping
  - XML: MethodCall with name "WriteLine" and target "Console"
  - Java AST: MethodInvocation "System.out.println"
  - Mapping: Simple 1-to-1 framework API replacement

✓ C2 (foreach): Structural change with type resolution
  - XML: <foreach> with <control> and <range>, Variable (var item)
  - Java AST: EnhancedForStatement with typed parameter and expression
  - Reorganization: "var item in items" → "String item : items"
  - Type inference: C# var resolved to explicit Java type (String)

✓ C3 (??): Complete pattern synthesis with recursive processing
  - XML: Binary operator between two operands
  - Java AST: ConditionalExpression with 3 components
  - Expansion: 1 operator → 3-part ternary with explicit null check
  - Handles nesting: Works inside method arguments via recursive conversion

✓ Combined Effect: Single C# line requires ALL THREE transformations
  - C1 handles API method mapping (Console.WriteLine → System.out.println)
  - C2 handles loop structure (foreach → enhanced for)
  - C3 handles null-coalescing operator (even inside method calls)
  - Result: Clean, idiomatic Java code

✓ Tool Validation: RefactoringMiner successfully transforms all three categories
